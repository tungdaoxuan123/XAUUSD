XAUUSD Trading System: Regime Robustness Implementation Plan                                                                                ││                                                                                                                                             ││ Background & Motivation                                                                                                                     ││ Analysis of the train_ensemble_gpu.py output revealed a significant regime discontinuity. The model failed to fire during validation (0%    ││ fire rate) but fired excessively during calibration (54%). This is because LightGBM learns absolute thresholds (e.g., atr_norm > 1.8),      ││ which break when the baseline market regime shifts.                                                                                         ││                                                                                                                                             ││ To fix this, we need a larger dataset spanning multiple regimes and regime-invariant features (Z-scores). Importantly, the chronological    ││ split (70/20/10) should be preserved to prevent temporal leakage; 1 year of data is sufficient to capture diverse regimes naturally across  ││ the temporal split. We also identified that the upstream event generator was aggressively filtering out low-volatility bars, artificially   ││ biasing the dataset before the model even sees it.                                                                                          ││                                                                                                                                             ││ Scope & Impact                                                                                                                              ││ This plan outlines a focused 4-step approach to resolve the regime discontinuity:                                                           ││  1. Data Expansion: Fetch 1 full year of M1 data.                                                                                           ││  2. Filter Relaxation: Lower the volatility threshold in the signal generator so the model can learn from low-volatility regimes.           ││  3. Data Processing: Re-run the labeling pipeline on the new dataset.                                                                       ││  4. Feature Normalization: Convert absolute microstructure features into regime-invariant rolling Z-scores.                                 ││                                                                                                                                             ││ Proposed Solution & Implementation Steps                                                                                                    ││                                                                                                                                             ││ Phase 1: Fetch 1-Year M1 Data                                                                                                               ││  * Action: Fetch 1 year of M1 XAUUSD data to provide a robust training set encompassing various market regimes.                             ││  * Command:                                                                                                                                 ││  1     python train_pipeline/fetch_data_dukascopy.py --from 2025-05-01 --to 2026-05-01 --out train_pipeline/data/xauusd_m1_1yr.csv          ││                                                                                                                                             ││ Phase 1.5: Relax ATR Filter                                                                                                                 ││  * Target File: train_pipeline/primary_signal_generator.py                                                                                  ││  * Action: Modify the volatility filter that determines which bars become "events".                                                         ││  * Details: Locate the ATR threshold logic and relax it from ATR > 0.8 * rolling_mean (or similar) to ATR > 0.5 * rolling_mean.
